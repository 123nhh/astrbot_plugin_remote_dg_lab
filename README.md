# DG-Lab-Play 郊狼玩法 ⚡

> 在群里和大家一起玩郊狼吧！

AstrBot 插件，通过 DG-Lab App 的 WebSocket 协议远程控制郊狼设备。支持多个玩家同时连接，提供丰富的群聊互动玩法。

移植自 [nonebot-plugin-dg-lab-play](https://github.com/Ljzd-PRO/nonebot-plugin-dg-lab-play)，原项目 BSD 3-Clause 许可证，Copyright © 2024 by Ljzd-PRO。

## 功能一览

### 基础指令

| 指令 | 说明 |
|---|---|
| `/绑定郊狼` | 生成二维码，用 DG-Lab App 扫码连接 |
| `/当前玩家` | 查看已连接的玩家列表 |
| `/退出游戏` | 断开自己的连接 |

### 强度控制

| 指令 | 说明 |
|---|---|
| `/加大强度 @用户 <百分比>` | 增加目标玩家的通道强度 |
| `/减小强度 @用户 <百分比>` | 减小目标玩家的通道强度 |
| `/当前强度 @用户` | 查看目标玩家的 A/B 通道强度 |
| `/随机强度 @用户` | 将目标强度随机设置为 0~100% |

### 波形控制

| 指令 | 说明 |
|---|---|
| `/可用波形` | 列出所有可用的波形名称 |
| `/增加波形 @用户 <波形名称>` | 将波形追加到目标的循环队列 |
| `/重置波形 @用户 <波形名称>` | 将目标的波形重设为指定波形 |
| `/当前波形 @用户` | 查看目标当前的波形循环 |
| `/随机波形 @用户` | 将目标波形随机设定 |

### 🎯 进阶玩法

| 指令 | 说明 |
|---|---|
| `/郊狼骰子 @用户` | 掷 D6 骰子，不同点数对应不同惩罚等级 |
| `/随机风暴 @用户 [秒] [次数]` | 在指定时间内随机变化多次强度和波形 |
| `/渐强惩罚 @用户 [秒] [最终%]` | 强度从 0% 线性攀升到目标百分比 |
| `/一键制裁 @用户 [秒]` | 满功率 + 随机波形持续轰炸（发起者 3次/h，被控者免审 1次/h，超出需被控者批准） |
| `/批准制裁` | 被控者批准待审批的制裁请求 |
| `/郊狼轮盘` | 随机选中一名在线玩家执行惩罚 |
| `/郊狼决斗 @用户` | 双方各掷 D6，点数小的一方受罚（差值×20% 强度） |
| `/猜数字 @用户` | 发起猜数字，目标 5 次机会猜 1-100，猜错按40% 惩罚，猜对则发起者受罚 |
| `/猜 <数字>` | 在猜数字游戏中提交答案 |
| `/接力惩罚 [起始%]` | 所有在线玩家依次接受递增惩罚（每人 +10%） |
| `/停止任务 @用户` | 紧急停止正在执行的玩法任务，强度归零 |
| `/护盾状态` | 私聊查看自己的反弹护盾状态 |

| 点数 | 名称 | 效果 |

| ⚀ 1 | 平安无事 | 什么都不发生 |
| ⚁ 2 | 微风拂过 | 10~30% 强度，持续 10 秒 |
| ⚂ 3 | 电流穿行 | 30~60% 强度，持续 20 秒 |
| ⚃ 4 | 雷霆洗礼 | 60~85% 强度，持续 30 秒 |

## 🛡️ 反弹护盾机制

每位玩家绑定后自动获得 **1 层反弹护盾**：

- 当受到惩罚类指令攻击时（骰子/风暴/渐强/制裁），护盾**自动触发**，将惩罚反弹给攻击者
- 护盾消耗后**每小时自动补充 1 层**，最多持有 1 层
- 攻击者**无法提前知道**对方是否有护盾，形成心理博弈
- 私聊发送 `/护盾状态` 可悄悄查看自己的护盾情况

## ⚔️ 郊狼决斗规则

`/郊狼决斗 @用户` — 双方各掷一次 D6：
- **点数大的获胜**，点数小的受罚
- 惩罚强度 = 差值 × 20%，持续 = 10 + 差值 × 5 秒
- **平局**：双方各受 15% 强度 8 秒

## 🔢 猜数字规则

`/猜数字 @用户` — 系统随机生成 1-100 的数字：
- 目标有 **5 次机会**猜数字（发送 `/猜 <数字>`）
- 每次猜错只提示**大了还是小了**，不透露具体偏差，同时按偏差比例暗中惩罚
- **偏差 ±5 以内算猜对**，惩罚反转，发起者受 50~80% 惩罚 20 秒
- **5 次用完**未猜对，最终惩罚 80%

## 🔗 接力惩罚规则

`/接力惩罚 [起始强度%]` — 依次传递递增惩罚：
- 随机排列所有在线玩家，依次执行惩罚
- 每位玩家强度 = 起始% + 序号 × 10%，最高 100%
- 起始强度默认 10%，可指定 5~50%

## 🤖 自动通过好友

启用后（默认开启），机器人会自动通过 QQ 好友请求，方便玩家私聊查看护盾状态等信息。

> 仅支持 aiocqhttp 平台（Napcat/Lagrange 等），可在配置中设置 `auto_accept_friend` 为 `false` 关闭。

## 🛡️ 一键制裁限制机制

为了保护被控者，一键制裁指令设有双重限制：

- **发起者限制**：每人每小时最多发起 **3 次**制裁，超出则提示剩余冷却时间
- **被控者限制**：每个被控者每小时免审 **1 次**，第 2 次起需被控者发送 `/批准制裁` 同意
- **审批超时**：待审批请求 30 秒内未批准则自动过期

## 内置波形

呼吸、潮汐、连击、快速按捏、按捏渐强、心跳节奏、压缩、节奏步伐、颗粒摩擦、渐变弹跳、波浪涟漪、雨水冲刷、变速敲击、信号灯、挑逗1、挑逗2

> 支持自定义波形：首次启动后在 `data/plugin_data/astrbot_plugin_remote_dg_lab/custom_pulse_data.json` 中编辑。

## 安装

1. 在 AstrBot WebUI 的插件市场中搜索安装，或手动 clone 到插件目录：

   ```bash
   cd <AstrBot>/data/plugins/
   git clone https://github.com/Ljzd-PRO/nonebot-plugin-dg-lab-play astrbot_plugin_remote_dg_lab
   ```

2. 安装依赖：

   ```bash
   pip install pydglab-ws qrcode[pil]
   ```

3. 重启 AstrBot 即可。

## 配置说明

在 AstrBot WebUI 中进入插件设置页面即可配置。有两种运行模式：

### 模式一：本地搭建 WebSocket 服务端（默认）

插件自行启动 WS 服务端，DG-Lab App 直接连接到你的服务器。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `remote_server` | `false` | 关闭远程模式，使用本地服务端 |
| `local_server_host` | `0.0.0.0` | 监听地址 |
| `local_server_port` | `4567` | 监听端口 |
| `local_server_publish_uri` | `ws://127.0.0.1:4567` | **⚠️ 必须改为公网可达的地址**，例如 `ws://你的公网IP:4567` |

### 模式二：连接远程 WebSocket 服务端

连接到外部已部署的 DG-Lab WS 中继服务。

| 配置项 | 说明 |
|---|---|
| `remote_server` | 设为 `true` |
| `remote_server_uri` | 远程服务端 URI，例如 `ws://my-server.net:8080` |

### SSL 配置（可选）

本地服务端模式下可启用 SSL 加密连接：

| 配置项 | 说明 |
|---|---|
| `local_server_secure` | 设为 `true` |
| `local_server_ssl_cert` | SSL 证书文件路径 |
| `local_server_ssl_key` | SSL 私钥文件路径 |
| `local_server_ssl_password` | 私钥密码（可选） |

> 启用 SSL 后，`local_server_publish_uri` 应改为 `wss://` 协议。

### 其他配置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `bind_timeout` | `90` | 扫码绑定超时（秒） |
| `register_timeout` | `30` | 终端注册超时（秒） |
| `duration_per_post` | `5.0` | 每次波形发送的最大持续时长（秒） |
| `post_interval` | `1.0` | 波形发送间隔（秒） |
| `sleep_after_clear` | `0.5` | 清空波形队列后的等待时间（秒） |
| `auto_accept_friend` | `true` | 自动通过好友请求（仅 aiocqhttp 平台） |

## 使用流程

1. 确保手机已安装 **DG-Lab App** 并连接了郊狼设备
2. 在群聊中发送 `/绑定郊狼`，插件会生成一个二维码
3. 用 DG-Lab App 扫描二维码完成绑定
4. 绑定成功后，群友就可以用各种指令控制你的设备了！
5. 发送 `/退出游戏` 断开连接
